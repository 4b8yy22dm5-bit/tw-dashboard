# 台股每日儀表板（tw-dashboard）

線上版：<https://4b8yy22dm5-bit.github.io/tw-dashboard/>

每日台股晨間／收盤簡報的靜態儀表板（繁體中文）：大盤與隔夜美股、自選燈號表（含「估價位置」參考欄）、盤中燈號時間軸、重點個股與估價參考帶、強／弱族群、權值股、衛星族群、新聞提要與短結（事實／判讀）。

- 價格顏色依台股慣例：**紅＝漲、綠＝跌**；警戒燈為 黃／橘／紅 圓角標籤，與價格顏色區隔。
- 預設顯示最新交易日；可用 `?d=YYYY-MM-DD` 或頁首「日期／封存」選單查看過去日期；`?tab=am|pm` 切換晨間／收盤，`?theme=dark` 深色模式。
- 結構：`index.html` + `assets/`（靜態模板）；`data/YYYY-MM-DD.json`（每日資料）；`data/index.json`（可用日期清單，新到舊）。盤中可分批更新燈號表與時間軸。

本站內容僅為既有簡報之事實整理與判讀，**不構成任何投資建議**、無下單指示、不保證任何報酬。「估價參考帶」與「估價位置」僅標示價格相對參考帶的位置，非買賣建議。

各區塊均標示**資料時間**（台北時間）與**資料來源**（如證交所、櫃買中心 MIS、Yahoo Finance、各新聞媒體等），頁首另顯示「最後更新」時間。資料可能延遲、不完整或有誤，請以證交所、櫃買中心及公司公告等官方資訊為準。
